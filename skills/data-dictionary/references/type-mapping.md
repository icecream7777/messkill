# MES 数据字典类型映射与字段设计规范

本规范适用于浦林成山 MES 系统数据字典设计与维护，确保所有数据表 Excel 文件与 SQL Server 物理表完全对齐。

---

## 1. 字段数据类型映射表

MES 数据字典在 Excel 中采用**单字符代码**简写标识数据类型：

| SQL Server 物理类型 | 数据字典代码 | 代码含义 | 长度填写规则 | 小数位填写规则 | 说明与典型用例 |
| :--- | :---: | :--- | :---: | :---: | :--- |
| `int`, `bigint`, `smallint`, `tinyint`, `bit` | **`I`** | Integer / 整型 | 空 | 空 | 主键 ID、计数 `COUNT`、状态枚举 `STATUS` |
| `nvarchar(n)`, `varchar(n)`, `nchar(n)`, `char(n)` | **`S`** | String / 字符串 | 填写字符数 $n$ | 空 | 工厂 `FAC(10)`、物料编码 `ITNBR(100)`、工号 `LOGNAM(50)` |
| `datetime`, `date`, `time`, `smalldatetime` | **`D`** | Date / 日期时间 | 空 | 空 | 创建时间 `CRTIM`、工厂日期 `WDATE`、写入时间 `WTIM` |
| `decimal(p, s)`, `numeric(p, s)`, `float` | **`N`** | Numeric / 数值型 | 填写精度 $p$ | 填写小数位 $s$ | 称重数量 `CZQTY(9, 3)`、产出重量 `WT(12, 3)` |
| `uniqueidentifier` | **`U`** | UUID | 空 | 空 | GUID 主键标识 |

## 2. MES 常用通用标准字段规范

在 MES 业务表设计中，推荐采用以下标准字段名称与定义：

| 字段名 | 物理类型 | 字典类型 | 推荐长度 | 中文描述 | 业务用途说明 |
| :--- | :--- | :---: | :---: | :--- | :--- |
| `ID` | `int IDENTITY(1,1)` | `I` | 空 | ID | 表自增主键 |
| `FAC` | `nvarchar(10)` | `S` | 10 | 工厂 | 工厂/车间代码（如 01, 02, 03, 0M0） |
| `WDATE` / `FACDATE` | `date` | `D` | 空 | 工厂日期 | 生产所属工厂业务日期（早班划分依据） |
| `WSHT` | `nvarchar(20)` / `(50)` | `S` | 20 / 50 | 班次 | 生产班次（1:夜班, 2:白班, 3:中班） |
| `ITNBR` | `nvarchar(100)` | `S` | 100 | 物料编码 | SAP 物料品号、规格代码 |
| `ITDSC` | `nvarchar(200)` | `S` | 200 | 物料描述 | 物料规格名称、品名规格 |
| `BARCODE` / `LOTID` | `nvarchar(100)` | `S` | 100 | 胎号/批次号 | 单品唯一条码、成型/硫化胎号 |
| `MCHID` | `nvarchar(100)` | `S` | 100 | 机台号 | 生产设备机台编号 |
| `QTY` | `decimal(9, 3)` | `N` | 9, 3 | 数量 | 生产或物料数量（精确到小数点后3位） |
| `COUNT` | `int` | `I` | 空 | 计件数量 | 计件考核或累加整型数量 |
| `LOGNAM` | `nvarchar(50)` | `S` | 50 | 工号 | 操作员工工号 / 登录账号 |
| `ENAM` / `NAME` | `nvarchar(50)` | `S` | 50 | 姓名 / 维护人 | 操作工姓名或系统记录维护人姓名 |
| `CRTIM` / `WTIM` | `datetime` | `D` | 空 | 创建时间 / 写入时间 | 记录物理生成入库时间（`GETDATE()`） |
| `UPTIM` | `datetime` | `D` | 空 | 更新时间 | 记录最新维护修改时间 |

## 3. Excel 数据字典样式规约

1. **表头第 1 行**：
   - A1 单元格：数据表物理编码（全大写，如 `LTA1019`），字体宋体 11pt。
   - B1 单元格：数据表中文描述（如 `返回胶班次库存统计表`），字体宋体 11pt。
2. **表头第 2 行（字段标头）**：
   - A2~F2：固定为 `列名`、`描述`、`类型`、`长度`、`小数位`、`备注`。
   - 样式：字体宋体 12pt、加粗（Bold）、填充黄色（Excel 默认黄色 Palette Index 4 / `#FFFF00`）、全包围细边框（Thin Border）、垂直居中。
3. **数据行（第 3 行开始）**：
   - 列 A（列名）：字体宋体 11pt，垂直居中。
   - 列 B（描述）：字体宋体 10pt，**全包围细实线边框（Thin Border）**，左对齐居中。
   - 列 C~F（类型/长度/小数位/备注）：字体宋体 11pt，居中对齐。
