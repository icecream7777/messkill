# MES 模块编码与数据表命名规范

本规范详细定义浦林成山 MES 系统的业务模块代码划分与数据表、文件命名规约。

---

## 1. 业务模块前缀分类代码 (Module Prefix)

MES 系统各业务领域统一采用三位英文字母进行前缀命名：

| 前缀代码 | 业务领域 | 核心职责与典型功能 | 典型数据表举例 |
| :---: | :--- | :--- | :--- |
| **`ED*`** | 基础数据建模 | 工厂建模、车间架构、数据配置、物料主数据、供应商管理 | `EDA0001` (车间), `EDA0004` (数据配置) |
| **`LT*`** | LOT 批次追溯 | 生产实绩、批次溯源、投料防错、设备机台绑定、计件考核 | `LTA0001` (硫化产出), `LTA1024` (静音棉计件) |
| **`LTA`** | 硫化/成型产出追溯 | 硫化与成型工序批次绑定、条码流转、计件核算 | `LTA1019` (返回胶库存), `LTA1023` (搬运胶囊计件) |
| **`LTB`** | 硫化工艺与产出 | 硫化投料、参数监控、报废记录、LCC 接口 | `LTB0002` (投料防错), `LTB0004` (硫化产出) |
| **`LTC`** | 胎坯及半成品追溯 | 压延、裁断、成型工序投入产出与缓冲库存 | `LTC0001` (胎坯追溯), `LTC0004` (半成品投入) |
| **`LTD`** | 密炼原材料追溯 | 胶料称量、小料称量、密炼投入与产出溯源 | `LTD0001` (炼胶追溯), `LTD0004` (密炼投入) |
| **`ST*`** | 仓储库存管理 | 厂内仓储、线边立库、移库盘点、呆滞料管理 | `STA0006` (盘点单), `STD0014` (胶料库存明细) |
| **`STE`** | 返回胶与再利用 | 返回胶历史库存统计、交接班库存结算、称重记录 | `STE0023` (称重记录), `STE0024` (班次库存) |
| **`CK*`** | 成品检查检测 | 外观检测、X光、均匀性、动平衡、全检、复检策略 | `CKA0001` (检测策略), `CKA0032` (停产规格) |
| **`QM*`** | 质量品质管控 | 实验室检验、物理机械性能测试、不合格品评审 | `QMD0001` (移库记录), `QMD0003` (返回胶称重) |
| **`IF_*`**| 系统间集成接口 | SAP、SRM、HR 考勤计件、APS 计划排产接口中间表 | `IF_HR_TABLE_08` (HR计件), `IF_RB_ML` (密炼) |

---

## 2. 数据字典文件命名规范

1. **命名格式**：
   $$\text{\{表名代码\}-\{中文描述\}.xlsx}$$
   例如：
   - `LTA1024-静音棉计件表.xlsx`
   - `LTA1019-返回胶班次库存统计表.xlsx`
   - `LTA1020-拆卷消耗履历表.xlsx`
   - `LTA1021-返回胶各班次库存汇总表.xlsx`
   - `LTA1023-半钢转运工搬运胶囊统计表.xlsx`
   - `LTA1025-拉坯转运产量统计表.xlsx`

2. **存储归档路径**：
   - 项目正式规范目录：`d:\git\mes-major\06-数据字典\{模块大类}\{子分类}\`
   - 个人或交付目录：桌面交付文件夹。
